# Sauce Demo – Requirements

## 1. Login
The user should be able to log in to the application using valid credentials.

## 2. Products
The user should be able to view the available products.

## 3. Product Details
The user should be able to view the details of a selected product.

## 4. Shopping Cart
The user should be able to add products to the shopping cart.

## 5. Remove Products
The user should be able to remove products from the shopping cart.

## 6. Checkout
The user should be able to complete the checkout process.

## 7. Logout
The user should be able to log out of the application.
